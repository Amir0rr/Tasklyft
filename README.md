# Tasklyft

Tasklyft, a responsive landing page for Todo app built with HTML/CSS/JS

![Desktop preview](/screenshots/desktop.png)

## Features
- Fully responsive layout (deskyop, tablet, moble)
- Custome fonts
- Smooth scroll
- Sign up

## Built With
- HTML
- CSS
- JavaScript

## What I Learned
- Work with media query
- Create respnsive layout with Flexbox/Grid
- FAQ popup
- Sign up validate

## Run locally
```bash
git clone https://github.com/Amir0rr/Tasklyft.git
```
Then open `index.html` in your browser.
